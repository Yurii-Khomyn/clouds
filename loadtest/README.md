# Навантажувальне тестування

Сценарій k6 для магазину: один віртуальний користувач у циклі робить 1 запис (`POST /orders`) і 8–10 читань.

## Запуск

Потрібен лише Docker (k6 береться з образу `grafana/k6`):

```bash
./loadtest/run.sh https://<адреса сайту> <кількість користувачів> <мітка>
# приклад
./loadtest/run.sh https://ca-homeshop.example.azurecontainerapps.io 100 demo
```

Адресу сайту показує `terraform output app_url`.

| Параметр | Значення |
|---|---|
| Фази | наростання 2 хв 30 с, стале навантаження 5 хв, спад 2 хв |
| Користувачів | 60 (1→2 екземпляри), 100–150 (повне навантаження) |
| Швидка перевірка сценарію | `FAST=1 ./loadtest/run.sh http://host.docker.internal:3000 3 smoke` (35 с, локально) |

Результат: підсумок у консолі й файли `loadtest/results/<мітка>.json` та `.txt`.

Опис сценарію, параметри й підсумкові звіти: [`docs/LOADTEST.md`](../docs/LOADTEST.md).
